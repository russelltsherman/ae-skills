## Risks
- The run finds one more question and asks it instead of writing (spec R6). The prompts of `writes-aligned-intent` and `existing-feature` answer scope, users, constraints and success and end with `Write it.`, and R6 sends any question still open to `## Open questions`, so a run that asks instead fails the Write graders.
- `llm` graders vote differently between runs, and `make evals` fails below a 1.0 score. Each `llm` grader judges one behaviour in plain criteria, and an `llm` grader with `focus: trace` sees only the first and last 12 messages, so it is used only for the Write call at the end of a run.
- The skill stops for a permission prompt on `date` when Claude changes the command (spec R12). `SKILL.md` gives the exact command, and the manual check runs without a prompt. Evals cannot catch this, because they grant `date` by `--allow-tools`.
- `SKILL.md` restates the template or naming rules (spec R3). The operator's review in Proof checks for this.
- The work-in-progress skill changes this repo's own `.specs/` (intent C12). Eval runs and manual checks run only in temporary directories.
- Billed runs cost money: four cases at three runs each per iteration. Step 4 asks the operator before each iteration's runs.
