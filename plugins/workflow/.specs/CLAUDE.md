# .specs

Planning documents for this repo. Before creating, finding or editing anything under `.specs/`, read the rule file for what you are touching.

| Rule file | Covers |
|---|---|
| `_rules/naming.md` | Change directory names, feature and change slugs, lookup |
| `_rules/intent_template.md` | `intent.md`: front matter, required sections, intent rules |
| `_rules/spec_template.md` | `spec.md`: front matter, required sections, spec rules |
| `_rules/plan_template.md` | `plan.md`: front matter, required sections, plan rules |
